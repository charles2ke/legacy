Add a profile

A profile is one small JSON file. You can create it entirely in your web browser — no tools to install.

Before you start

  • Share only what you have permission to share, including any photos.
  • Writing about someone else? You need appropriate authorisation from that person, or from whoever is entitled to act for them.
  • Do not include birth dates, addresses, private contact details, passwords or account access. This repository is public.
  • Removal is possible, but copies, forks and Git history may persist elsewhere afterwards.

Steps

  1. Open the profile template and copy its contents.
  2. Go to the new file page for the profiles/ folder and name your file your-slug.json, using lowercase letters, numbers and hyphens.
  3. Paste the template, replace the example text with your own, and delete any optional fields you do not want.
  4. Add the same slug to profiles/index.json.
  5. Choose “Create a new branch and start a pull request”, then fill in the checklist in the pull request template.

What happens next

Automated checks confirm the file is valid. A maintainer then reviews it against the moderation checklist — consent, private information, impersonation, harassment and unauthorised copyrighted material — and either merges it or explains what needs changing. Maintainers are volunteers, so review may take a while.

Publishing here is not permanent hosting and does not verify anyone's identity. Keep your own copy of anything you care about.

Questions about what is appropriate to share? Open a discussion or issue and describe the situation without including private details.
